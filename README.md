# The Chair

A night apartment, first person, in the browser.

https://iamtew.github.io/thechair/

## Run locally

From this folder, with a network connection (Three.js and PixiJS load from jsDelivr):

```
python -m http.server 5173
```

Open http://127.0.0.1:5173/

## Controls

Desktop: click to look, WASD to walk, E to use, Esc to release the mouse. If the browser will not capture the pointer, hold the mouse button and drag.

Phone: drag the left side to walk, the right side to look, tap Use.

You start in the entrance. The Chesterfield is in the bedroom, past the foot of the bed. The box on the side table opens. Inside: a note, cigarettes, an ashtray, and a Zippo. Take the cigarettes and the ashtray out. E on the pack smokes. E on the ashtray ashes. E on empty air puts the cigarette out. The pack does not run out.
